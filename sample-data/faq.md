# Fleet Telemetry FAQ

## How long is raw telemetry kept?

Raw events are kept for 90 days in the raw event store.

## Who owns the ingestion gateway?

The platform ingestion team owns the gateway and its certificate validation rules.

## Can a team read the raw event store directly?

Only the billing team has direct read access. Other teams use the analytics store.

## Which schema version should new device types use?

Schema version 4.
